# RF-001: Mostrar información de la cpu.
- Descripción: El programa ha de enseñar al usuario los datos referentes a la cpu del sistema: modelo, frecuencia número de hilos, número de núcleos físicos y memoria caché disponible por nivel (L1 y L2).
- El total de memoria Cache L1 es la suma de todas las memorias caché L1 disponibles en el sistema.
- El total de memoria Caché L2 es la suma de todas las memorias caché L2 disponibles en el sistema.
- La salida tendrá el siguiente formato:
```
CPU INFORMATION
----------------------------------------
Model: AMD Ryzen 7 5700U with Radeon Graphics
Frequency: 4372.00 MHz
Cores: 8 cores / 16 threads
Cache L1: 512 KB
Cache L2: 4 Mb

```
- Criterios de aceptacion: 
-- Se muestra por pantalla el modelo
-- Se muestra por pantalla la frecuencia de la CPU
-- Se muestra por pantalla la caché disponible.
